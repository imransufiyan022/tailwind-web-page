Tailwind’s base styles already give images max-width: 100% and height: auto, which prevents most images from overflowing their containers. Tailwind CSS However, we should still apply suitable utilities depending on how the image will be used. A. Basic responsive image The simplest responsive image pattern is: Meaning --------------------------------------------------------- Utility | Meaning | --------------------------------------------------------- block | Displays the image as a block element | w-full | Makes it occupy 100% of its parent’s width | h-auto | Calculates the height automatically | alt | Describes the image for accessibility | --------------------------------------------------------- External CSS equivalent: img { display: block; width: 100%; height: auto; } This pattern shows the entire image without changing its natural proportions. B. Place the image inside a responsive container The image responds to the width of its parent. Therefore, the parent container must also be responsive.
Here: - w-full allows the container to shrink on small screens. - max-w-sm prevents it from becoming excessively wide. - The image occupies the full width of that container. C. h-auto versus a fixed height Use h-auto to show the entire image This is suitable when: - The complete image must remain visible. - The original image proportions should be preserved. - All images have similar natural dimensions. Use a fixed height with object-cover This is suitable when: - Several card images must have the same height. - The image needs to fill a defined area. - Some cropping is acceptable. The object-cover utility makes the image fill its container while preserving its proportions. Parts of the image may be cropped. Tailwind CSS D. Understanding object-cover External CSS equivalent: img { width: 100%; height: 256px; object-fit: cover; } Without object-cover, forcing both width and height can stretch the image. Incorrect: The browser may force the image into the given dimensions. Better: The image keeps its proportions and crops any part that does not fit. E. Understanding object-contain object-contain makes the entire image visible inside the specified area. External CSS equivalent: img { width: 100%; height: 256px; object-fit: contain; } It may leave empty space around the image. --------------------------------------------------------------------------- | Utility | Result | Best used for | |-----------------|------------------------------|------------------------| | `object-cover` | Fills the area but may crop | Product cards, profile pictures and hero images | | `object-contain`| Displays the complete image but may leave space | Logos, icons and product cut-outs | | `object-fill` | Stretches the image to fill the area | Usually avoid for photographs | | `object-scale-down` | Keeps the original size or reduces it | Images that should not be enlarged | --------------------------------------------------------------------------- F. Use aspect ratio for consistent images An aspect ratio describes the relationship between an image’s width and height. Square image aspect-square means: aspect-ratio: 1 / 1; The width and height are equal. Landscape image Video-shaped image aspect-video uses a 16 / 9 ratio. Tailwind provides aspect-square, aspect-video and other ratio utilities. ---------------------------------------- 20. TAILWIND CSS BREAKPOINTS What is a breakpoint? A breakpoint is a specified screen width at which a webpage changes its layout or styling. For example: - Cards may appear in one column on a phone. - They may appear in two columns on a tablet. - They may appear in four columns on a desktop. In external CSS, we create breakpoints with media queries: .card-container { display: grid; grid-template-columns: 1fr; } @media (min-width: 768px) { .card-container { grid-template-columns: repeat(2, 1fr); } } In Tailwind CSS, we use responsive prefixes:

Tailwind normally works in the opposite direction:
